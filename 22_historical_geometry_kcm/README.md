# Historical Geometry / KCM Lineage

This branch preserves the older KCM/FCC/Kagome/stacked-Kagome/pyrochlore, graph-force, coarse-metric, compact-cell, 3D-lift, curvature, and historical cosmology/geometry models that preceded or run alongside the present H504/Q72 formulation.

These objects are preserved for provenance and comparison. A historical geometry is not silently promoted into current H504 canon merely because later work reuses similar language or topology.
