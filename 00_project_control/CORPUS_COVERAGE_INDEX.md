## Completion gate

The public project is corpus-complete only when every owner-approved public recovered item is represented by one canonical object ID plus zero or more aliases/version links and these counters are all zero:

- orphan public items
- unmapped public source files
- unresolved duplicate identities
- public historical names without provenance pointers
- promoted computational results without proof/code/verifier pointers
