# Alias and Version Policy

One mathematical/scientific object may have many historical names, filenames, package paths, chat labels and release versions. These are aliases, not separate truths.

Canonical identity fields:

- `object_id`
- `canonical_name`
- `object_type`
- `branch`
- `status`
- `source_paths[]`
- `aliases[]`
- `versions[]`
- `sha256[]` when bytes exist
- `supersedes[]`
- `superseded_by[]`
- `proof_or_verifier[]`
- `notes`

No alias is deleted merely because a later name is preferred.
