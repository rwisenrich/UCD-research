# UCD v21: executable and Lean proof gate

Automated source verification for the UCD v21 six-perspective continuation and the four-frontier research.

**Python:** exact Kelvin geometry, BCC fourth-moment and bivector identities, characteristic-two CSS matrices and ranks, both X/Z distance-five witnesses, and source-derived numerical comparisons. Additional frontier programs reproduce SU(3) gauge covariance, electroweak tests, gravity and the stored Nt=8 simulation checks.

**Lean:** a pinned Lean 4 / Mathlib workspace, with the 14 v21 finite-arithmetic theorems, the 14 four-frontier finite-arithmetic theorems, and a separate lossless-split and Schur-identity module. Lean compilation verifies exactly these theorem declarations, not a claim that the complete continuum Yang-Mills monograph has been formalized.

**Automation:** GitHub Actions triggers on pull requests, pushes to the default branch and a weekly schedule. Failed jobs remain visible. Original papers and historical source archives are unchanged.

Source: UCD v21 verified Master, 2026-11-10. Exact source files are copied unmodified into `checks/` and `lean4/UCDVerification/`. Data is always recomputed or separately identified as archived simulation measurements.
