# Archaeology / Metrology

This branch preserves the Taş Tepeler and related archaeology/metrology program: regional geometry and planning, remote-sensing datasets, common-module uncertainty analysis, anti-numerology jitter tests, exact-discriminator / Gate-8 screening, negative-control sites, unit/cadence bridges, measurement extraction, notation disambiguation, semantic normalization, and calibration architecture.

Negative results are retained as part of the method, including exact-discriminator failures and metrological non-identifiability results.
